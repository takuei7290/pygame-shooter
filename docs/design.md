# 設計メモ

縦スクロールシューティングを pygame で作る。
学習しながら作るので、この設計は「たたき台」。作りながら見直していく。

## 1. 仕様（何を作るか）

| 項目 | 内容 |
|---|---|
| 画面 | 縦長 600×800 |
| 自機 | 矢印キーで移動、スペースで弾を撃つ |
| 敵 | 上から出てきて下に進む。弾が当たると消えてスコア加算 |
| 終了条件 | 敵にぶつかったらゲームオーバー |
| 見た目 | 最初は色付きの四角。画像は後で差し替える |

## 2. ゲームループ

1秒に60回、次を繰り返す。**更新と描画は分ける。**

```
while 実行中:
    dt = 前フレームからの経過秒数
    1. 入力を受け取る   (handle_events)
    2. 状態を更新する   (update)  … 移動・当たり判定・スコア
    3. 画面に描く       (draw)    … 背景 → キャラ → UI
```

## 3. ファイル構成とクラス

```
src/shooter/
├─ __init__.py   … 入口。Game を作って run() するだけ
├─ settings.py   … 定数（数字）置き場
├─ game.py       … Game：ゲームループと全体の管理（監督）
├─ player.py     … Player：自機
├─ bullet.py     … Bullet：弾
└─ enemy.py      … Enemy：敵
```

- Player / Bullet / Enemy は `pygame.sprite.Sprite` を継承し、
  `__init__`（image と rect を用意）と `update(dt)`（自分で動く）を持つ
- Game は全員に `update(dt)` を呼び、全員を描くだけ。キャラの動き方は知らない

### キャラの管理（Sprite Group）

| グループ | 用途 |
|---|---|
| `all_sprites` | 全キャラ。まとめて update・描画する |
| `bullets` | 弾だけ。当たり判定用 |
| `enemies` | 敵だけ。当たり判定用 |

## 4. ルール

- 数字は `settings.py` にだけ書く（コードに直接書かない）
- 移動は「1秒あたりの速さ × dt」で計算する（PCの性能で速さが変わらないように）
  - `dt = clock.tick(FPS) / 1000`
- キャラは自分の動きだけを担当し、他のキャラのことは知らない
- キャラ同士の関係（当たり判定・スコア）は Game が担当する

## 5. 作る順番

1. ウィンドウを出して、自機を動かす
2. 弾を撃てるようにする
3. 敵を出す
4. 当たり判定とスコア
5. ゲームオーバーとリトライ（ここでシーン管理を導入）

## 6. 後で決めること

- 敵の出現パターン・速さ・数
- 弾の連射間隔
- スコアの点数
- 画像・音
- タイトル画面・ゲームオーバー画面の作り
