## 複数行のコメントと docstring

**Python に複数行コメント専用の書き方はない。各行に `#` を付ける。ファイル・クラス・関数の先頭の説明は `"""` の docstring で書く。**

| | `#` | `"""` （docstring） |
|---|---|---|
| 正体 | コメント（読み飛ばされる） | 文字列（説明書として残る） |
| 使いどころ | 途中の補足、一時的な無効化 | ファイル・クラス・関数の一番最初 |

- VS Code では行を選んで `Ctrl + /` で `#` をまとめて付け外しできる
- docstring は import した先でマウスを乗せると説明として表示される
- コードの途中に `"""` を置いてコメント代わりにはしない（使われない文字列になるだけ）

```python
"""定数置き場。

数字はここにだけ書く。
"""

# 画面の大きさ
SCREEN_WIDTH = 600
```
